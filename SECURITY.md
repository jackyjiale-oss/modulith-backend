# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report it privately through GitHub: **[Report a vulnerability](https://github.com/jackyjiale-oss/modulith-backend/security/advisories/new)** (Security tab → "Report a vulnerability"). Include affected versions, reproduction steps and impact. You can expect an acknowledgement within 5 working days and a status update at least every 14 days until it is resolved.

## Supported versions

Only the latest released minor version of `Modulith.Backend.Templates` receives security fixes. Projects generated from the template own their code; re-generate or apply the published fix manually.
